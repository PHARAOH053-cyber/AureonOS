WELCOME TO: AureonOS

to start: download the .zip and uncompress it, then go exactly at: AureonOS (2nd one) then type CMD in the explorer

then type: "STARTUP"

for command list type: "help"

know the version that you are in by typing: "version"

you can start timers, read files by writing this command: "analysis port1" (or "port2")
